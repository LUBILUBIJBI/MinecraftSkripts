\# Server Announcement Script (/announcement)



\### Description

Allows authorized staff members to broadcast server-wide announcements to all online players.



\### Requirements \& Permissions

\- \*\*Permission:\*\* `announcement`

\- \*\*Permission Message:\*\* \&cYou do not have permission to execute this command!



\### Commands

\- `/announcement <text>` - Broadcasts a formatted message to all players.
