\# Clear Chat Script (/cc)



\### Description

Clears the global server chat by broadcasting empty lines and notifies all players who executed the chat clear.



\### Requirements \& Permissions

\- \*\*Permission:\*\* `op`

\- \*\*Permission Message:\*\* \&cYou do not have permission to execute this command!



\### Commands

\- `/cc` - Clears the chat globally (1000 empty lines).
