\# Server Update Archive System



\### Description

A GUI-based news archive system. Admins can add or edit server update logs, which are stored as books in a 54-slot chest GUI accessible to all players.



\### Features

\- \*\*Auto-Shift Archive:\*\* Shift existing update entries automatically so entry #1 is always the newest update.

\- \*\*Linebreaks:\*\* Supports `<nl>` for line breaks inside books.

\- \*\*Copy Functionality:\*\* Shift-Left clicking an entry in the GUI prints the update text into chat for easy copying.

\- \*\*Join Notification:\*\* Alerts players on join if update entries exist.



\### Commands \& Permissions

\- `/updateset <text>` \*(OP)\* - Pushes a new update log to slot #1.

\- `/updateedit <number> <text>` \*(OP)\* - Edits a specific existing update entry.

\- `/update` - Opens the Server News Archive GUI.
