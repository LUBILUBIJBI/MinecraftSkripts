\# Force Chat Script (/chat)



\### Description

Allows administrators to force a specified target player to send a specific chat message.



\### Requirements \& Permissions

\- \*\*Permission:\*\* `op`

\- \*\*Permission Message:\*\* \&cYou are not allowed to do this!



\### Commands

\- `/chat <player> <text>` - Forces the specified player to state the input text in chat.
